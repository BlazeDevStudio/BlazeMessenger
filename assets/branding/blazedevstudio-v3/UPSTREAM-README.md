# BlazeDevStudio brand assets — verified v3

The artwork in this folder was imported from the owner-approved **BlazeDevStudio** Google Drive folder on 2026-10-30. These are actual SVG path assets, **not screenshot crops**.

## Usage
- Main site hero: `main-hud-transparent.svg` (the same reconstructed B shape across projects).
- Website favicon: `ruby-target-favicon-compact.svg` (the detachable ruby HUD).
- Main brand mark: `main-hud.svg`. Plain-dot edition: `main-plain.svg`.
- Auxiliary Z: `auxiliary-Z-badge.svg`, for CDN/dependency labeling **only**.
- Eight category icons: `sublogos/`.
- Twelve portable outlined slash wordmarks: `wordmarks/`.
- Fifteen application layouts: `mockups/`.

The full 8K renders and audited source references are preserved in the [owner's Drive brand folder](https://drive.google.com/drive/folders/10L7iVO2U2FLteckOkRtO6HqGhSPLPMdb), renamed **BlazeDevStudio**. Geometry test reports measured a 96.4% B reference-mask overlap and 99.3% Z overlap; the original authoring vectors were not available, so these are audited reconstructions, not claims of pixel identity.

Legacy v2 reconstructions were removed from the current repository tree to avoid mixing incompatible brand masters; Git history is retained.
